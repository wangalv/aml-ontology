FinCrime Semantic Layer

What a semantic layer is, and why it matters. A semantic layer is the shared, machine-readable definition of what the business's terms mean and how they relate, together with the rules a valid record must follow. It is the foundation of an AI and agentic architecture. Without it, each agent has to work out the meaning of the data on its own. With it, agents share the same context, so a term means the same to every system and agent, and they can use deductive reasoning, because explicit relations and rules let a conclusion be derived and checked rather than guessed.

Applied to financial crime, this is how it can look. Here the vocabulary covers typologies and risk indicators, alerts, cases and findings, and the data sources that evidence them. The demo shows it in use: the model reads and writes, the semantic layer supplies the context and the rules, and code checks the model against them.
