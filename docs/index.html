FinCrime Semantic Layer

The FinCrime semantic layer is the shared, machine-readable vocabulary of financial crime: typologies and risk indicators, alerts, cases and findings, the data sources that evidence them, how they relate, and the rules a valid record must follow. AI agents need it: it gives them context, so a term means the same to every system and agent, and it supports deductive reasoning, because explicit relations and rules let a conclusion be derived and checked rather than guessed. This demo shows it in use: the model reads and writes, the semantic layer supplies the context and the rules, and code checks the model against them.
